## 2️⃣ **브랜드 감성 톤 요약**

### Dear.A (Shine On Me Nail Colour)의 감성 특징:

- **핵심 톤:** 밝고·투명한·시럽 같은·로맨틱·감각적
- **메시지 전략:**
  - **시각적 감각 중심:** "맑게 올라오는 시럽 광택감", "Pinterest mood nail" 등 구체적 시각 디테일 강조
  - **비건·친환경 가치:** VEGAN FORMULA를 핵심 차별점으로 반복 강조
  - **색상명의 시적 네이밍:** "브리즈 인 썸머", "페라다이스 오로라", "라일락 미스트" 등 감성적 작명
  - **리뷰 활용:** 실구매 평점 4.7과 실사용자 언어 그대로 인용
  - **Pinterest 감성:** MZ세대가 추구하는 "나만의 무드" 연출 강조

- **전체 흐름:**
  1. 제품 정보 → 2. 감성 후킹 → 3. 컬러 라인업 → 4. 기능적 강점 → 5. 친환경 가치 → 6~9. 개별 색상 상세 → 10. 리뷰 증명 → 11. 감성 재강조 → 12. CTA → 13. 사용 팁

## 3️⃣ **우리 브랜드(SOROI)와의 차이점 요약**

| 비교 항목 | Dear.A (경쟁사) 특징 | SOROI (우리 브랜드) 방향성 제안 |
|------------|----------------------|-------------------------------|
| **감성 톤** | 밝고·투명한·시럽 같은·로맨틱·Pinterest 감성 | **정돈된·절제된·조화로운** - 일본 감성의 미니멀리즘 |
| **핵심 가치** | VEGAN FORMULA (친환경·비건) | **"갖추다(揃い)" 철학** - 립·블러셔·네일이 이미 조화롭게 완성됨 |
| **키워드 사용** | "시럽", "광택감", "Pinterest mood", "비건" | **"톤온톤", "조화", "완성형", "나만의 컬러 톤"** |
| **후킹 전략** | 35가지 개별 컬러의 다양성 강조 | **6가지 세트 구성의 편의성** - "색 조합 고민 제로" |
| **메시지 구조** | 제품 정보 → 감성 → 컬러 상세 → 리뷰 → 감성 → CTA | **페인포인트 공감 → 세트 솔루션 제시 → 철학 전달 → 증명 → CTA** |
| **CTA 문장** | "Check List - ~하시는 분" (4가지 공감 포인트) | **"색을 고르는 시간 대신, 바르는 순간을 즐기세요"** (선택 피로 해소) |
| **차별 포인트** | 개별 제품의 색상 다양성 (35색) + 비건 | **세트 구성의 조화** (립·블러셔·네일 한 벌) + 일본 감성 철학 |
| **리뷰 활용** | "맑게 올라오는 시럽 광택감이 너무 예뻐요" (시각적 디테일) | **"밝은 피부부터 어두운 엄마까지 둘 다 써도 잘 어울립니다"** (범용성·세대 공감) |

### 📌 핵심 차이점 요약:

**Dear.A:**  
- "35가지 중 네가 원하는 색을 골라라" (선택의 즐거움)
- 개별 제품의 감각적 디테일 (시럽·광택·Pinterest 무드)
- 비건·친환경 가치

**SOROI:**  
- **"우리가 이미 조화롭게 완성해두었다"** (선택 피로 해소)
- **세트 구성의 편의성** (립·블러셔·네일 한 번에)
- **"갖추다(揃い)" 철학** - 정돈되고 절제된 일본 감성

## 4️⃣ **다음 단계 연결 문장**

> **6단계(주요 소구점 작성)에서는, 위에서 분석한 경쟁사와의 감성 톤 차이를 바탕으로 우리 브랜드만의 USP(Unique Selling Proposition) 메시지를 작성합니다.**
>
> **특히, 경쟁사가 "35가지 개별 색상의 다양성"으로 소구하는 반면, SOROI는 "립·블러셔·네일 톤온톤 세트의 조화로움"이라는 차별 포인트를 중심으로, 3단계에서 검증된 페르소나(민지: 색 조합 고민의 피로 / 수현: 간편한 메이크업)의 페인포인트를 직접 해결하는 메시지를 구성합니다.**
>
> **4단계에서 도출한 SEO 키워드("시럽네일 립블러셔세트 톤온톤", "일본감성 데일리")와 브랜드 감성 키워드("조화로움", "간편한", "나만의 컬러 톤")를 자연스럽게 녹여내어, 페르소나별 맞춤 카피 초안을 작성합니다.**
