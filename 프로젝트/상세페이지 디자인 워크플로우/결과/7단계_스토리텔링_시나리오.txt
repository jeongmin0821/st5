## 2️⃣ **스토리 전개 흐름 요약**

> **공감(페르소나의 불편함: "또 고민하셨나요?")  
> → 해결(세트 솔루션: "당신을 위해 완성해두었습니다" + "한 세트로")  
> → 감성 연결(브랜드 철학: "갖추다(揃い)" + "투명한 혈색")  
> → 증명(범용성 + 리뷰: "엄마와 딸" + "실사용자 목소리")  
> → 제품 소개(6가지 컬러 라인업: "Memory of Sakura")  
> → 비교(경쟁사 차별화: "SOROI 세트 구성" + "선택해야 하는 이유")  
> → CTA(행동 유도: "지금, SOROI와 함께")**

### 📌 구조 특징:
- 경쟁사(Dear.A)가 "제품 정보 → 감성 → 컬러 → 리뷰 → CTA" 순서로 진행하는 것과 달리,  
- **SOROI는 페인포인트 공감부터 시작**하여 고객의 감정 여정을 먼저 건드림
- "갖추다(揃い)" 철학을 중반부에 배치하여 브랜드 아이덴티티 각인
- 리뷰와 범용성을 연속 배치하여 신뢰 강화
- 비교 섹션을 후반부에 두어 "왜 우리 브랜드인가" 명확히 제시

## 4️⃣ **브랜드 일관성 체크**

| 항목 | 평가 | 비고 |
|------|------|------|
| **SEO 키워드 자연스럽게 포함** | ✅ | "시럽네일", "톤온톤", "일본감성 데일리", "립블러셔세트" 모두 반영. 키워드가 문장 흐름을 해치지 않음 |
| **브랜드 톤(정돈된·절제된·감각적) 유지** | ✅ | • "불필요한 것을 덜어낸" (절제)<br>• "정돈된 무드" (정돈)<br>• "계절을 품은 이름" (감각적)<br>→ 1단계 브랜드 톤앤매너 일관성 유지 |
| **감성/정보 문장 비율** | 감성 60% : 정보 40% | • 감성: 구간 1, 2, 4, 6, 7, 8, 11<br>• 정보: 구간 3, 5, 9, 10<br>→ 브랜드 톤에 맞춰 감성 중심 구성 |
| **CTA 명확성** | ✅ | 구간 11 "지금, SOROI와 함께" → 행동 유도 문장 명확. "당신의 일상에 조화를 더하는" 베네핏 재강조 |
| **페르소나별 메시지 균형** | ✅ | • 민지(24세): 구간 1, 2, 4, 6, 7, 8<br>• 수현(47세): 구간 3, 5, 9<br>→ Primary(민지) 메시지 비중 높으나, 수현 니즈도 반영 |
| **브랜드명(SOROI) 노출** | ✅ | 구간 9, 10, 11 총 3회 등장. 후반부 집중 배치로 브랜드 각인 |

## 5️⃣ **경쟁사 대비 차별화 포인트 요약**

| 구분 | Dear.A (경쟁사) | SOROI (우리 브랜드) |
|------|----------------|-------------------|
| **스토리 시작** | 제품 정보 → 감성 후킹 | **페인포인트 공감** → 해결 제시 |
| **핵심 메시지** | "35가지 중 네가 골라" (선택의 즐거움) | **"우리가 이미 완성해둠"** (선택 피로 해소) |
| **철학 전달** | 비건·친환경 가치 강조 | **"갖추다(揃い)" 철학** - 일본 감성 미니멀리즘 |
| **리뷰 활용** | "시럽 광택감 예뻐요" (시각 디테일) | **"엄마와 딸이 함께"** (세대 공감·범용성) |
| **CTA 방식** | "Check List - ~하시는 분" (공감 나열) | **"색 고르는 시간 대신, 바르는 순간을"** (베네핏 재강조) |

## 6️⃣ **다음 단계 연결 문장**

> **8단계(비주얼 콘텐츠 준비 및 입력 정보 정리)에서는, 위에서 완성한 11개 스토리 구간별로 필요한 이미지 리스트와 가비아 제디터 입력 정보를 정리합니다.**
>
> **각 구간의 대표 문장·보조 문장을 기반으로, 어떤 비주얼이 필요한지(제품 컷 / 모델 컷 / 텍스트 배너 / 색상 스와치 등)를 명세하고, 제디터 템플릿에 입력할 텍스트·이미지 순서·레이아웃 구성을 정리하여 9단계 디자인 작업에 바로 투입할 수 있도록 준비합니다.**
>
> **특히, 구간 4 "갖추다(揃い) 철학"과 구간 6 "6가지 컬러 라인업"은 브랜드 정체성을 시각적으로 각인시키는 핵심 섹션이므로, 일본 감성 미니멀 디자인과 색상 스와치의 배치·여백을 중점적으로 기획합니다.**
